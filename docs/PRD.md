# TasteVerse PRD

TasteVerse is a browser based pixel art cultural adventure. The player chooses cultural interests, explores one town, talks to three distinct residents, and plans a movie, music, and food themed night. Qloo supplies real cultural signals; DeepSeek interprets player input and explains recommendations; deterministic game rules update relationships, score the plan, and select an ending.

## P0 player journey

1. Select movie, music, and food interests.
2. Explore one Phaser map with keyboard movement and three interactive NPCs.
3. Collect clues through conversations and see task progress.
4. Submit a plan using selections or free text.
5. Inspect evidence backed suggestions, score, and NPC reactions.
6. Reach Perfect Harmony, Mixed Night, or Cultural Chaos according to saved state.

The demo must remain playable after a recoverable API failure and must show when cultural evidence is unavailable. No fabricated Qloo result may be presented as real evidence.
